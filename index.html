解释与使用边界

  • 候选基因来自功能注释、结构域、GO/KEGG、同源命中和专题关键字筛选，不等同于实验验证结果。
  • 目前完整基因注释、CDS、蛋白和 JBrowse 轨道已接入花魔芋；白魔芋、珠芽魔芋和疣柄魔芋仍需完整基因集后再导入搜索库。
  • 用于论文、报告或公开数据发布前，应核对 PlantGARDEN、ZEN、NCBI、GO、KEGG、InterPro、Pfam、PlantTFDB 的正式引用和许可要求。
  • 使用本站结果发表或展示时，建议同时引用原始基因组、注释和外部数据库来源。

说明：本站整合花魔芋基因组、基因结构、功能注释、序列检索、基因组浏览器和 BLAST 查询；表达矩阵和共表达网络可在后续版本继续加入。

Help

使用帮助

搜索示例

  • 精确 gene ID：evm.model.HIC_ASM_10.860_Akon
  • 物种前缀：AK:evm.model.HIC_ASM_10.860_Akon 或 AKevm.model.HIC_ASM_10.860_Akon
  • 结构域：PF00069、IPR000719
  • GO：GO:0003677 或 DNA binding
  • 魔芋关键词：KGM、CSLA、WRKY
  • 转录因子：WRKY、MYB、bHLH

基因组浏览器

基因详情页提供“在基因组浏览器中查看”入口，可跳转到对应坐标并显示基因结构。

如果轨道加载较慢，请等待参考序列和 GFF 轨道完成加载后再操作视图。

常见问题

  • 如果 URL 中带有 #search?q=... 或 #gene/...，刷新后会恢复到对应视图。
  • 搜索栏旁的物种选择可限制搜索范围；不选择时搜索当前已接入的全部基因记录。
  • BLAST 任务提交后可能需要等待计算节点处理，刷新任务可查看最新状态。
  • 表达图谱和多物种比较将在获得完整表达矩阵或其他物种基因集后加入。
